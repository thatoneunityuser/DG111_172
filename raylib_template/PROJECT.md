## 🔁 Flow การทำงาน (Flowchart)

> แก้ไข diagram ด้านล่างให้ตรงกับงานของกลุ่ม (เขียนด้วย Mermaid — ดูผลได้ใน VS Code / GitHub) หรือวาดด้วยเครื่องมืออื่นแล้วแนบรูป

```mermaid
flowchart TD
    A([Start]) --> B[/Incorrect/Correct = 0/]
B -->C[Random Code/Image]
C --> D{Error?} 
D --NO--> Q{Correct?}
D--YES-->F{Which Error?}
F -- Error1 -->Q{Correct?}
F -- Error 2 -->Q{Correct?} 
F -- Error 3-->Q{Correct?}
Q -- Yes --> GetCorrect[Correct ++]
GetCorrect --> CorrectCount{Is Correct = 10 ?}
CorrectCount -- No --> C
CorrectCount -- Yes --> Win
Win --> Z([End])
Q-- Correct with Error1 or 2 --> Fix[/Fix code/]
Fix --> Q
Q --Incorrect --> GetIncorrect[/Incorrect++/]
GetIncorrect --> In{Incorrect =3}
In -- NO--> C
In --Yes--> GameOver
GameOver --> Z
EE[Error look at you] -->EOS{English or Spanish}
EOS -- English --> Nothing
EOS -- Spanish--> Z


  
```

**State ของโปรแกรม:เก**

```mermaid
stateDiagram-v2

    PLAYING --> GAME_OVER : [เงื่อนไข]
    GAME_OVER --> TITLE : [เงื่อนไข]
```
